# Code of Conduct

PocketWebGames is a small open-source hobby project. We want everyone to feel
welcome to play with it, file issues, and contribute.

## Our pledge

Be kind. Be patient. Assume good faith. When in doubt, ask.

Contributors of all backgrounds and skill levels are welcome.

## What we expect

- Be respectful and constructive in issues, pull requests and code reviews.
- Focus on the work, not the person.
- Help newcomers — everyone was new once.

## What is not okay

Behavior that makes other contributors feel unsafe or unwelcome is not okay
and may lead to removal from the project's spaces. If you are unsure whether
something crosses the line, it probably does — ask first.

## Reporting

If you experience or witness behavior that breaks this code of conduct,
please contact the maintainer privately at **marcel.duetscher@gmail.com**.
Reports will be handled confidentially.

## Scope

This code applies to all project spaces — the GitHub repository, issues,
pull requests, and any related discussion channels.
